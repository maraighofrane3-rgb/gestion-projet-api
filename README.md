## 📋 Description

This is a REST API for managing projects and tasks. It features:
- **User Management**: JWT authentication with roles (`user` and `manager`)
- **Project Management**: CRUD operations with role-based visibility
- **Task Management**: CRUD operations with manager-only assignment
- **Search & Sort**: Filtering and sorting for projects and tasks
- **Role-Based Access Control**: Managers have elevated permissions

---

## 🛠️ Tech Stack

- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **Authentication**: JWT (JSON Web Tokens)
- **Password Hashing**: bcryptjs
- **Environment Variables**: dotenv
